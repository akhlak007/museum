# Louvre Guardian - Implementation Roadmap

## Phase 1 - Foundations

- Formal documentation, source ledger, requirements register, asset manifest, TypeScript application, tests, and Supabase migrations.

## Phase 2 - Room 711 runtime

- Authored modular Room 711 reconstruction, third-person controller, camera, collisions, interaction system, one guard, one visitor, one sensor, and optimized lighting.

## Phase 3 - Integrated security slice

- HUD, minimap, full map, dashboard, artifact panel, mission objectives, incident banner, radio/guard command, protocol workflow, report, and scoring.

## Phase 4 - Cloud validation

- Supabase authentication, RLS verification, cloud incident/action/progress persistence, connection status, and honest demo fallback.

## Phase 5 - Quality gate

- Unit/integration/end-to-end tests, real-browser inspection, performance profiling, accessibility review, console audit, and five-weakest-areas correction.

## Phase 6 - Connected Denon milestone

- Add nearby Level 1 rooms and portal streaming, expand artifact/resource management, camera review, patrol assignments, false alarms, and investigation missions.

## Later milestones

- Three-wing/five-level map coverage.
- Additional recognizable galleries and landmarks.
- Advanced NPC schedules and crowd behavior.
- Missing-artifact investigations and safe chase/interception missions.
- Admin user/policy configuration and museum-wide security assessment.
